# 風險與條款

Kano Proxy 是非官方的獨立專案。透過它使用訂閱帳號，可能違反該供應商的條款，也已經有供應商限制這樣使用的帳號。連接帳號前，請先讀完這一頁。

第一次登入時，app 會用一份簡短的使用說明列出同樣幾點。說明改版時會再問一次。你要勾選方塊並按 **Agree and continue**，才能開始使用。

## 連接訂閱帳號時會發生什麼

為了使用訂閱帳號，Kano Proxy 會照該供應商官方命令列工具的方式登入和送出請求。這些請求從 Kano Proxy 所在的伺服器送出，不是從供應商的 app 送出。

Claude Code、Codex、Grok 和 Antigravity 帳號都是這樣。自訂端點和本機模型不一樣：你用的是自己的 API 金鑰或自己的模型伺服器，請求會送到你指定的地方。

## 使用說明的各點

- **沒有隸屬關係。** Kano Proxy 與 Anthropic、OpenAI、Google、xAI 沒有關係，也沒有獲得它們背書。這些名稱和商標屬於各公司，這裡提到只是為了說明 Kano Proxy 能接哪些帳號。
- **用官方工具的方式登入。** 在供應商自己的 app 以外這樣使用，可能違反該供應商的條款。
- **帳號可能被限制。** 已經有供應商在沒有預警的情況下，限制、停用或永久封鎖這樣使用的帳號。供應商怎麼處置你的帳號，是你和該供應商之間的事，Kano Proxy 無法撤銷。
- **只用自己的帳號。** 只連接你自己持有、並判斷可以這樣使用的帳號。多數供應商禁止分享帳號或轉售使用權。如果你透過 Kano Proxy 分享帳號，責任由你承擔。
- **端點可能失效。** Kano Proxy 使用的供應商端點沒有公開文件。供應商隨時可能更改，帳號也可能在 Kano Proxy 更新前無法使用。
- **依現狀提供。** 軟體以 MIT 授權釋出，不提供任何保證。你要為自己連接的帳號、金鑰和使用方式負責。

你能怎麼使用帳號，由各供應商自己的條款決定。連接前請先讀過。條款會更新，請讀最新版本。

## 由別人代管的站台

Kano Proxy 也可能由別人架設給你用。營運者可能有自己的服務條款和隱私權聲明。登入頁會附上連結，使用說明也會請你一併同意。
